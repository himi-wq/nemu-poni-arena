# ねむポニアリーナ

## 概要

「ねむポニアリーナ」は、眠ノポニのゆめかわな雰囲気をもとにしたオリジナルの2D Webミニゲームです。プレイヤーは「ポニ」を操作し、アリーナ内にランダム出現する「ゆめのかけら」を集めて、自陣の「ゆめゴール」へ届けます。

まずは1人用のスコアアタック形式として実装しています。制限時間は3分で、残り30秒はゴール時スコアが2倍になります。敵キャラ「ねむけモンスター」に当たると所持ポイントの一部を失い、フィールドには障害物や回復エリアも配置されています。

## 技術構成

- Next.js App Router
- TypeScript
- Phaser.js
- Tailwind CSS
- npm

## セットアップ手順

```bash
npm install
```

## 開発サーバー起動方法

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開いて確認します。

## ディレクトリ構成

```text
src/
  app/
    page.tsx          # トップ画面
    play/page.tsx     # ゲーム画面
    result/page.tsx   # リザルト画面
    ranking/page.tsx  # ランキング仮画面
    globals.css       # グローバルスタイル
    layout.tsx        # ルートレイアウト
  components/
    GameClient.tsx    # Phaserをクライアントサイドで初期化するコンポーネント
  game/
    constants.ts      # ゲーム定数
    NemuPoniArenaScene.ts # Phaserシーンとゲームロジック
    types.ts          # ゲーム関連型定義
```

## 注意事項

本プロジェクトは完全なオリジナル作品であり、既存の公式ゲーム・キャラクター・素材とは関係ありません。タイトル、UI、キャラクター、技名、素材はいずれもオリジナルの仮実装として作成しています。

現在のランキング保存は未実装で、`/ranking` は仮UIのみです。画像素材は丸・四角・絵文字風の仮表現を使用しており、後から差し替えやすいようにゲーム定数とPhaserシーンを分離しています。
